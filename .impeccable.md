## Design Context

### Users
This is a personal daily todo for its creator on their Apple Silicon Mac. It stays beside web browsing and work, can be collapsed into a floating dot, and provides a daily record plus an AI-readable interface.

### Brand Personality
Quiet, clean, elegant. English-only interface with very short functional labels. User-authored tasks can be in any language. No slogans, encouragement paragraphs, productivity pressure, gamification, or clutter.

### Aesthetic Direction
The creator explicitly requests a white, modern, minimal layout with very few buttons. A compact white paper-like surface, warm graphite text, subtle sage green checks, generous breathing room. The history page resembles a calm journal with a GitHub-style activity grid.

### Design Principles
- Today comes first. Expose secondary controls only on hover or in the menu.
- The floating window fades when attention moves elsewhere and becomes clear on hover.
- Completion has a short drawn check and gentle text transition. Respect reduced motion.
- Data is real and local. Empty days remain empty; sample data is explicitly labeled.
- Use readable typography with CJK fallback for user content, keyboard navigation, and visible focus states.
- Remove decorative copy. The widget should show only date, Today, tasks, the add field, and a numeric completion count.
- Priority can be chosen before creation beside Add a task. A compact rounded popover uses a horizontal continuous native slider, a large white thumb, four detents, and smoothly changing fill colors. Existing task dots open the same control. Gentle breathing only during interaction.
- Default ordering puts pending priorities first and completed tasks last. Manual row placement overrides both priority and completion grouping, persists across reloads, and never changes the task priority itself.
