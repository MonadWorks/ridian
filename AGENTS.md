# Repository conventions

- Keep `README.md` (English) and `README.zh-CN.md` (Simplified Chinese) complete and equivalent. Update both in the same change.
- Keep the clickable language buttons at the top of both READMEs, with working relative links.
- README screenshots must contain only empty states or synthetic data. Keep credentials, personal tasks, and desktop context out of public assets, and label previews from earlier versions.
